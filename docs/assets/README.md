# README screenshots

Synthetic screenshots used by the repository overview and public documentation. Filenames
**must match exactly** because public pages reference each by name. These illustrate the actual
application UI with seeded examples, built-in defaults or scoped browser fixtures; they do not
represent a real tenant, verified cloud collection, actual billing or executed AI investigation.

## Workflow screenshot collection

The [visual tour]({{ site.baseurl }}/reference/visual-tour/) links critical operational,
identity, investigation and setup workflows. Its detailed guides use the versioned
[screenshot manifest]({{ site.baseurl }}/assets/screenshots/manifest.json), with capture routes,
source notes, dimensions and content hashes. Each screenshot include supplies an explanatory
caption, synthetic-data notice and full-size link. The filenames below remain aliases for
repository-overview consumers; use the manifest-named images for detailed walkthroughs.
